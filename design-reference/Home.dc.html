6Home — a hub that answers, not a menu that lists

The page in front of everything, built so each calculator works alone or as part of the full run. Two things make it a hub rather than a table of contents. First, every card carries a live number computed from your city before you have entered anything: "Closing day in Winnipeg — about $16,000" is a reason to tap, "Closing Costs →" is not. Second, the cards have two states in the same provenance vocabulary the tables already use — typical while they run on city defaults, yours once you have been inside, so the hub turns into a dashboard as you go. Nothing is gated: where a tool would sharpen with an input you have not given, the card says which one and takes you to that single question rather than to a six-step wizard. The mode switch sets how much of the product you are using — one errand, or the guided run that fills the shared inputs so every tool sharpens at once — and the depth control inside each tool remains the separate axis of how much detail you want. Location and language sit here so both are chosen once, before any tool opens.
